# es7210

Espressif's ES7210 driver (four-channel microphone ADC), as LilyGO ships it in
[Xinyuan-LilyGO/T-Embed](https://github.com/Xinyuan-LilyGO/T-Embed) `examples/mic/` (`es7210.cpp`, `es7210.h`,
`audio_hal.h`), unchanged, under the ESPRESSIF MIT License in each file's header. The plain T-Embed and the T-Embed
SI4732 hear through it (companion C-66; `src/talk.cpp`).
